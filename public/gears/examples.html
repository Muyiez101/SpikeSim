Gears examples

These are the examples included by Gears. Download a file, return to Code & simulate, and use the File menu to load its blocks or Python. Load world files through Worlds → Load World.

  • Pen drawing — blocks
  • Pen tracing — Python
  • Python modules: main program, library.py, lib2.py. Keep these three files together.
  • Image texture world
  • World without a floor
  • Randomized world
  • WRO 2021 Elementary example
  • WRO 2021 Junior example

The full FLL and WRO fields are available in Code & simulate → Worlds → Select World → Missions (FLL, WRO, etc).
